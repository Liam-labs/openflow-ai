# Self-hosted fonts

Latin-subset variable WOFF2 files from Google Fonts, loaded with `next/font/local`
so production builds never fetch fonts over the network (a failed fetch fails a
Turbopack build). All are licensed under the SIL Open Font License 1.1.

| File | Family | Axes |
|---|---|---|
| CrimsonPro-latin.woff2 | Crimson Pro | wght 400-700 |
| CrimsonPro-Italic-latin.woff2 | Crimson Pro Italic | wght 400-700 |
| IBMPlexSans-latin.woff2 | IBM Plex Sans | wght 400-600 used |
| InstrumentSans-latin.woff2 | Instrument Sans | wght 400-700 |
