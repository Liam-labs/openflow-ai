# Frontend Aesthetics

The discovery gate applies only to genuinely blank-slate visual work with no approved direction. An existing brand, design system, established product language, supplied reference, or project-approved direction wins; continue from it without reopening discovery.
When the work is genuinely blank-slate, load `/design-reference-discovery`; after its board, `awaiting-selection` blocks visual product mutation until a use-one/combine choice, and Refine keeps that gate active.
The execution hook verifies the current channel/board/revision/fingerprints before visual mutation; cached prose is not authority. A gate failure blocks only the gated visual mutation, not the whole assignment.
Use `/art-directed-frontend`, `/frontend-aesthetics`, `/visual-assets`, and `/visual-review` only for the visual work they cover.
