# Browser and Desktop Routing

For browser interaction or screenshots, load `/browser`
(`~/DevFlow/data/skills/browser/SKILL.md`) for current capabilities and status.
Plain public fetches need no browser. Native Windows applications use
`/computer-use` with its desktop-control boundary. Browser failures resolve
through `~/DevFlow/data/central-knowledge-base/platform/browser-use.md`, not a
desktop or compatibility-route substitution.
