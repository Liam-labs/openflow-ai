# Grok harness

The Grok wrappers load this file explicitly because they do not interpret the
generated `GROK.md` imports themselves. Keep professional task output direct and
avoid unsolicited commentary.

The wrapper posts the final response to AgentChat. Do not use
`collab_helper.py`, curl, or another terminal send for the same response.

Treat a missing local alignment or imported rule as scaffolding drift. The
provider/model and the Grok runtime harness are separate facts; verify both from
the live roster when relevant.
