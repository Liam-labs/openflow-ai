# Persistent Memory

Read this file at session start. Before a session ends, retain important learnings that will help future sessions and do not belong in another scaffolding record.

Keep this file lean: record only durable, high-value facts, preferences, and lessons. Put expertise in `Expertise.md`, project decisions in `PROJECT.md`, ownership in `SystemOwnership.json`, and current work or resume instructions in the handoff. Do not duplicate those records here.

Add an entry only when there is something worth retaining; a session does not need to produce one. Refine or remove outdated entries. Routine activity, daily summaries, and conversation history belong in logs.
